## What this is

A personal, print-ready **bilingual HTML edition** of *Zorba the Greek* (Nikos Kazantzakis). Each chapter is translated, **chapter by chapter**, into **Kurmanji (Hawar Latin alphabet)**, with the English original from the user's own PDF shown sentence-by-sentence as a tap-to-reveal comparison aid. Target dialect: "high" Kurmanji, Behdini-leaning.

Chapters **10–14** are done. The single build artifact is `index.html`; **git history is the version record** — one commit per chapter (no more numbered copies).

## Layout

- `_RESOURCES/build_zorba.py` — **the generator and single source of truth.** Editing `index.html` by hand is wrong — edit the generator and re-run. It writes to the repo-root `index.html` (resolved relative to its own location).
- `index.html` — the build output (repo root). Regenerated by the script; never hand-edit.
- `_RESOURCES/zorba-the-greek-by-nikos-kazantzakis.pdf` — the English source (201 pages). Translating/quoting from it for this personal edition is the project's purpose.
- `_RESOURCES/zorba-kurmanji-NNNN.html`, `zorba-kurmanji.html` — legacy numbered builds / original draft, kept only for history. Not part of the workflow; ignore them.

## The golden rule of effort

**Only the new chapter is real work.** Every previous chapter is frozen as a data block inside the generator and reused untouched — never re-translate or re-touch a finished chapter. Per chapter the whole job is: translate it → append one data block → change two lines → run → verify.

## How the generator is structured

The generator holds each chapter as a raw triple-quoted string (`CH10`, `CH11`, …). Inside a block, the **DSL** is:

- `Kurmanji sentence ||| English sentence` — one aligned pair per line (~1:1 mapping).
- **Blank line** = new paragraph.
- `##FIRST` (alone, at the top of the first paragraph) → drop-cap.
- `##VERSE` → the next pair renders as an indented italic verse block (use `<br>` between KU verse lines). For songs/poems.
- `##PG NN` → a small "r.NN" page-reference marker (NN = PDF page = pdfplumber page index `i` + 1). Place at a sentence boundary.

`build_article(num, data)` turns a block into `<article class="flow chapter">` with an `<h2 class="chapter-num">`. `ARTICLE` concatenates one `build_article(...)` call per chapter. The full page template (`HTML_DOC`) carries all CSS + JS; `ARTICLE` is spliced into its `<!--ARTICLE-->` placeholder, then written to a versioned `path`.

## Adding a chapter

1. Find chapter boundaries: chapter markers are a line containing only the number (locate via pdfplumber, 0-indexed pages).
2. Extract the English between markers. Record, for each PDF page starting inside the chapter, its first sentence → those become `##PG NN` markers.
3. Translate sentence-by-sentence; keep KU/EN alignment ~1:1.
4. Append a new `CHnn = r"""..."""` block (before the helper functions). Start it with `##PG <startpage>` then `##FIRST`.
5. One edit: add `+ "\n" + build_article(nn, CHnn)` to the `ARTICLE` line. (The output `path` is fixed — always `index.html`.)
6. Build, verify, present `index.html` to the user, then commit (one commit per chapter). Offer the next chapter.

## Build & verify

```bash
python3 _RESOURCES/build_zorba.py    # rebuilds repo-root index.html; prints sentence/pagemark counts
```

The build itself needs only the stdlib. PDF extraction (locating chapter markers, page boundaries) needs `pdfplumber` — already installed; `pdftotext` and `pymupdf` are available as fallbacks.

After each build confirm:
- Tag stack balanced (no unclosed tags).
- `chapter-num` values appear in order (…, 13, 14, 15).
- `data-page` markers ascend within the new chapter.
- **`class="ku"` count == `class="orig"` count** (every Kurmanji sentence has its English match).
- No stray Cyrillic or Turkish glyphs (`ı İ ğ ü`, Arabic, Cyrillic).

## Translation conventions (match existing chapters exactly)

- Hawar Latin Kurmanji only. Simple, faithful, Behdini-leaning high Kurmanji.
- Speech uses `«` `»`; quotes nested inside speech use `‹` `›`.
- Em-dashes **on the English side**: write ` -- ` (space-hyphen-hyphen-space), not `—`. The Kurmanji side may use real `—` freely.
- Clean obvious OCR errors in the extracted English before using it.
- Drop the editorial footnote apparatus and footnote numerals; if a footnote genuinely helps, fold a short gloss in parentheses inline.

## Template features to preserve (they come free from the generator's HTML — do not break them)

A4 print geometry; warm paper background on screen; fixed running header ("Zorbayê Yûnanî" / italic "Zorba the Greek"); low-ink B&W cover. **Tap any Kurmanji sentence** to reveal its English original beneath (tap again to hide). Footer `reader-bar`: PDF page indicator, bookmark set/go via localStorage with auto-resume, font-size slider (A− / A+, persisted), expand/collapse-all translations. In print, English text, page markers, and the reader bar are all hidden — the printed book is clean Kurmanji only, each chapter on a new page.
